# 院系管理员审核功能使用指南

## 功能概述

院系管理员审核功能允许系统管理员查看、审核和管理院系管理员的注册申请。系统管理员可以选择通过或拒绝申请，从而控制谁可以成为院系管理员。

## 数据准备

1. 运行以下SQL脚本初始化测试数据：

```sql
mysql -u your_username -p your_database < sql/init_admin_data.sql
```

这将创建必要的表结构并添加4个测试用的院系管理员申请。

## 使用步骤

### 1. 系统管理员登录

1. 访问系统登录页面: http://localhost:8082/
2. 点击"管理员入口"
3. 使用系统管理员账号登录：
   - 用户名: admin
   - 密码: admin123

### 2. 查看待审核申请

登录后，主控制台将显示待审核的院系管理员申请数量。

- 查看详情方式1：点击控制台中的"院系管理员审核"卡片
- 查看详情方式2：从左侧菜单中选择"院系管理员审核"

### 3. 审核申请

在院系管理员审核页面，您可以：

1. 查看所有待审核的申请
2. 点击每行中的"展开"按钮查看申请人的详细信息
3. 对每个申请执行以下操作：
   - 点击"通过"按钮审核通过申请
   - 点击"拒绝"按钮拒绝申请

### 4. 查看已审核申请

在院系管理员审核页面，使用顶部的标签页切换查看不同状态的申请：

- "待审核"：显示等待审核的申请
- "已通过"：显示已经审核通过的申请
- "未通过"：显示被拒绝的申请

## API说明

后端已实现的API：

- `GET /sysadmin/findapply`：获取所有院系管理员申请
- `GET /sysadmin/agree?acid={id}`：通过指定ID的申请
- `GET /sysadmin/disagree?acid={id}`：拒绝指定ID的申请

## 常见问题

**Q: 没有看到任何待审核的申请怎么办？**

A: 请确保您已运行初始化脚本。如果仍没有显示，可能是因为所有申请已经被审核。您可以修改数据库中的记录状态或者添加新的申请记录。

**Q: 审核操作失败怎么办？**

A: 请检查后端日志是否有错误信息。常见原因包括数据库连接问题或权限不足。确保您使用了正确的系统管理员账号登录。
